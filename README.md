# 👋 안녕하세요, 신입 백엔드 개발자 채성실입니다!

8년간 정부지원 IT교육 행정 실무를 총괄하며 **기획력과 실행력**을 쌓아왔고,  
현재는 실무 중심의 프로젝트 경험을 통해 **개발자로서의 전문성**을 키워가고 있습니다.  
특히, **그룹웨어 시스템(7FS) 프로젝트**에서 기획부터 개발, UI/UX, 배포까지 전 과정을 경험했습니다.

## 🧑‍💻 주요 프로젝트

### 🚀 [7FS 그룹웨어 협업 시스템](https://github.com/SeongSil-Chae/GrooBear)
> 기업 내 협업을 효율적으로 지원하는 웹 기반 그룹웨어 시스템

- **담당 역할**: 프로젝트 관리 모듈 전담 개발, UI/UX 기획, 구조 설계
- **주요 기능**:
  - 프로젝트 등록/수정 (5단계 입력폼 + 조직도 + 파일 업로드)
  - 업무 계층 구조, 피드백 댓글 및 실시간 알림 (WebSocket)
  - Gantt 차트(DHTMLX API), Kanban 보드 (Drag&Drop)
  - Ajax 기반 SPA 유사 구조 설계
  - 업무 엑셀 다운로드, 권한별 접근 제어 등
  - VO 분리 구조 설계: GanttTaskVO / KanbanTaskVO / ProjectTaskEntity

## 🎓 교육 과정 (대덕인재개발원)

> 2024.10 ~ 2025.05 (총 1240시간) 풀스택 기반 실무 프로젝트 중심 교육 과정

**✔ 실무 중심 프로젝트 2회 진행**
- 스킬업 프로젝트: JSP 기반 프로젝트 설계 및 구현, ERD 모델링 및 협업 개발 수행
- 실무 프로젝트: Spring Boot + React 기반 시스템 구현

**✔ 주요 커리큘럼**
- **Java 프로그래밍**: 객체지향, 예외처리, 컬렉션, IO, JDBC, Servlet 기반 웹 프로그래밍
- **JSP 기반 서버 구축**: EL/JSTL, MVC 구조, REST 패러다임 적용
- **Spring REST 서버 구축**: Spring MVC, AOP, Boot, Security, Token 인증, API 테스트
- **Vanilla JS & AJAX**: ES6, 비동기통신, DOM 제어, File API, jQuery 기반 UI 처리
- **React/Node 서버 개발**: React Hooks, Router, 게시판 UI/UX, Express API 서버 연동
- **RDB 설계 및 활용**: Oracle SQL, Join/서브쿼리, PL/SQL, 정규화 및 모델링
- **UI 구현 및 웹표준**: 웹 레이아웃, CSS 레이아웃 구성, 반응형 구조 설계
- **AWS & Docker**: 리눅스 서버 구성, Git/SVN, Jenkins CI/CD, Docker 컨테이너화
- **데이터아키텍처**: ERD 모델링, 정규화/반정규화, 관계설계

## 📈 저의 강점

- **기획 + 개발 경험의 조화**: 전직 기획자로서 요구사항을 빠르게 분석하고 정확하게 구현합니다.
- **실행력 있는 협업가**: 개발 중단 위기를 극복하고 팀 전체를 완주시키는 실행력과 리더십 보유
- **사용자 중심의 UI/UX 개선 주도**: 실제 사용성을 고려한 SPA 구조, 실시간 알림, 피드백 시스템 직접 설계
